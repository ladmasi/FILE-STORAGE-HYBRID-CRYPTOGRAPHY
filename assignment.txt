2. List and explain the different functions and their modes for writing into a file.
ans) File functions in PHP provide a powerful set of tools for handling files and directories within web applications.
These functions allow developers to create, read, write, delete, and manipulate files and directories, providing the ability to manage file-related operations seamlessly.
PHP file functions support file system operations such as checking file existence, determining file size, setting file permissions, and working with file timestamps.
These functions also facilitate file manipulation and analysis, including searching for specific patterns within files, extracting subsets of data, and manipulating file paths.
Each function utilizes different modes to specify how you want to interact with the file when writing data:
File Opening Modes:
"w" (Write Only): Creates a new file for writing. If the file already exists, it is overwritten.
"a" (Append Only): Opens a file for appending data to the end of its content.
"r+" (Read/Write): Opens a file for both reading and writing. The file pointer is positioned at the beginning.
"w+" (Write/Read): Creates a new file for writing and reading. If the file exists, it is overwritten.
"a+" (Append/Read): Opens a file for appending data and reading. The file pointer is positioned at the end.
"x" (Create New Only): Creates a new file for writing, but fails if the file already exists.
